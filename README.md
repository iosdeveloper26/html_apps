# html_apps

This repository manages HTML apps generated by Agent Butler's harness, Butler Claw. Each app is a self-contained page you can open in a browser. No install or server is required.

## Apps

| Project name | Introduction | URL |
| --- | --- | --- |
| Diet & Recipe Manager | Tracks recipes and daily meals in the browser, including calories, protein, and carbs, with all data kept in local storage. | https://github.com/iosdeveloper26/html_apps/blob/main/habit/diet_recipe_app/index.html |

Open an app by opening its `index.html` in Chrome, Firefox, Safari, or Edge.
