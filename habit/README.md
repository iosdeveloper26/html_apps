# Projects Repository

## Overview

This repository contains a collection of web applications and projects built using Claude (Anthropic) and Butler Claw Pro as the development harness and AI model. Each project is self-contained and demonstrates different web application patterns and functionality.

## Projects

### Diet & Recipe Manager

A web application for tracking meals and managing recipes with local browser storage.

**Basic Functions:**
- Add, view, and manage recipes
- Track daily meal intake
- Store all data locally in browser (no server required)
- Search and filter recipes
- Calculate nutritional information

**How to Use:**
1. Open `diet_recipe_app/index.html` in your web browser
2. Use the interface to add new recipes by entering recipe name, ingredients, and instructions
3. Log your meals by selecting recipes and adding portion sizes
4. View your meal history and nutritional summaries
5. All data persists in your browser's local storage

## Author & Tools

**Development Tools:**
- Model: Claude (Anthropic)
- Harness: Butler Claw Pro
- Language: HTML, CSS, JavaScript
- Storage: Browser LocalStorage

## Getting Started

Each application is standalone and requires only a modern web browser. Simply navigate to the index.html file in each project folder and open it in your browser. No installation, build process, or server setup is needed.

## Browser Compatibility

These applications work best in modern browsers (Chrome, Firefox, Safari, Edge) with JavaScript and LocalStorage support enabled.
